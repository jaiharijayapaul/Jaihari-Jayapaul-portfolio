# Personal Portfolio

A modern, responsive, and interactive personal portfolio website built with React and Vite. This portfolio showcases my skills, experience, projects, and educational background as an aspiring Data Engineer and AI/ML Engineer.

## 🚀 Features

- **Modern UI/UX**: Sleek design with glassmorphism effects and custom cursors.
- **Interactive Animations**: Scroll animations using AOS (Animate On Scroll) and 3D tilt effects using `react-tilt`.
- **Responsive Design**: Fully responsive layout that looks great on desktops, tablets, and mobile devices.
- **Dynamic Components**: Modular React components for About, Skills, Projects, Experience, Education, and more.
- **Performance Optimized**: Fast rendering and optimized build using Vite.

## 🛠️ Technologies Used

- **Frontend Framework**: React (with React Hooks)
- **Build Tool**: Vite
- **Styling**: Custom CSS (Vanilla CSS with modern features)
- **Animations**: AOS (Animate On Scroll), React Tilt
- **Icons**: FontAwesome

## 💻 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone <your-repo-url>
   ```

2. Navigate to the project directory
   ```bash
   cd Portfolio
   ```

3. Install NPM packages
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```
   
5. Build for production
   ```bash
   npm run build
   ```

## 🏗️ Project Structure

The project is structured into modular React components for easy maintenance and scalability:

- `src/components/Hero.jsx`: Landing section with introduction.
- `src/components/About.jsx`: Information about my skills and background.
- `src/components/Skills.jsx`: Technical skills and tools.
- `src/components/Projects.jsx`: Showcase of my recent projects.
- `src/components/Experience.jsx`: Professional work experience and internships.
- `src/components/Education.jsx`: Academic background.
- `src/components/Contact.jsx`: Contact form and links.
- `src/index.css`: Global styles and design system variables.
